# Design Patterns in Java 25 & Spring Boot 4.0.6

This project aims to provide practical, modern examples of various software Design Patterns implemented in Java 25. It leverages Spring Boot 4.0.6 and Lombok to demonstrate how these patterns can be integrated into modern application development, highlighting both pure Java implementations and Spring-assisted approaches.

## Project Structure

This project is structured as a multi-module Maven project. The parent `pom.xml` manages the versions for Java (25), Spring Boot (4.0.6), and Lombok. Each design pattern is isolated within its own module.
